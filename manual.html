操作手冊

拍一張食物照片，AI 幫你辨識品項並估算卡路里，紀錄自動存在你自己的瀏覽器裡。

操作步驟

  1. 展開「⚙️ AI 連線設定」，選擇服務商並填入你自己的 API 金鑰（Claude、OpenAI、Gemini、OpenRouter 擇一，需選擇支援圖片辨識的模型）
  2. 按「📁 拍照 / 選擇照片」——手機會直接開啟相機，桌機則會開啟檔案選取視窗；桌機也可以改按「📷 使用電腦鏡頭」直接在網頁裡拍照
  3. 選填「補充說明」（例如份量、特殊食材），可以幫助 AI 估算更準確
  4. 按「🔍 AI 估算卡路里」，稍候幾秒後會出現可編輯的品項表格（食物名稱／份量／卡路里），可以直接修改任何欄位，也可以增刪項目
  5. 確認無誤後按「💾 儲存紀錄」，這筆紀錄就會存進「歷史紀錄」清單，並計入「今日總計」
本工具沒有規則式的離線估算——AI 沒有金鑰無法運作，這是刻意的設計：估算食物卡路里需要真正的圖片辨識能力，沒有辦法用簡單規則猜測。

歷史紀錄與編輯

「歷史紀錄」每一筆是一張卡片，點一下可以展開看完整品項明細與補充說明。每筆紀錄可以：

  • 編輯：把這筆紀錄的照片與品項重新載入到上方的編輯區，修改後按「儲存紀錄」即可原地更新（不會變成新的一筆）
  • 刪除：永久移除這筆紀錄，無法復原

月份飲食分析與建議

選一個月份，按「📊 產生本月分析與建議」：

  1. 本工具會先在本機統計這個月的資料（記錄天數、總攝取、平均每天卡路里、攝取最高／最低的一天、最常吃的食物）——這些數字是直接算出來的，不經過 AI，保證正確
  2. 接著把這些統計數據送給 AI，請它針對「這些既定數字」撰寫飲食狀況分析與具體建議，AI 不會也不需要重新計算任何數字
需要先在「AI 連線設定」填好金鑰才能使用；沒有任何紀錄的月份只會顯示統計為零，不會呼叫 AI。分析內容僅供健康管理參考，不是醫療診斷。

備份與匯出

  • 下載完整備份（.json）：把所有紀錄（含照片）匯出成一個檔案，換手機或清除瀏覽器資料前建議先備份
  • 匯入備份（.json）：選擇之前下載的備份檔即可還原，匯入是合併（依 id 覆蓋），不會刪除目前已有的其他紀錄
  • 下載 CSV（不含圖片）：把日期、品項、份量、卡路里整理成表格，方便匯入 Excel 自行分析

加入主畫面（可選）

頁尾按「📲 加入主畫面」，可以把這個工具像 App 一樣安裝到手機或電腦桌面，吃飯時打開就能立刻拍照記錄。

  • Android（Chrome）／桌面 Chrome、Edge：按下按鈕會直接跳出安裝確認視窗
  • iPhone／iPad（Safari）：按下按鈕會提示改用「分享」圖示 → 「加入主畫面」
  • Mac 桌面版 Safari：會提示改用選單列「檔案」→「加入 Dock」（Safari 17 以上）

隱私說明

  • 所有紀錄（含照片）只存在你自己瀏覽器的 IndexedDB，不會傳送到本工具的任何伺服器——因為本工具沒有伺服器
  • 按下「AI 估算卡路里」時，照片與補充說明會直接從你的瀏覽器送到你自己選擇的 AI 服務商官方 API，不經過任何中間伺服器；API 金鑰也只存在瀏覽器的 localStorage
  • 換裝置、換瀏覽器，或清除瀏覽器資料，紀錄都會遺失，請務必用「下載完整備份」定期存檔

使用警語

請注意：
  • AI 估算的卡路里僅供參考，並非精確的營養分析，實際熱量依食材、烹調方式、份量而有差異
  • 請勿將本工具的估算結果作為醫療、疾病控制或飲食治療的唯一依據，有相關需求請諮詢專業營養師或醫師
  • 請勿在照片或補充說明中包含他人的臉部、個資或其他敏感資訊
  • 使用 AI 估算功能所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費
  • 本工具與創作者不對使用估算結果後所產生之任何後果負責
